# Templates

This directory can hold reusable templates for engineering tasks and common deliverables.

## Planned template types

- pull request templates
- issue templates
- ADR templates
- release checklist templates
- onboarding checklists
- code review rubric drafts

## Example use

Use templates to standardize repeatable work and reduce decision fatigue across the team.

```text
templates/
├── README.md
├── pull-request-template.md
├── issue-template.md
├── adr-template.md
└── release-checklist.md
```

## Guidance

Choose templates that are easy to fill out and intentionally narrow in scope. Templates should guide behavior, not create extra overhead.

---

This structure is intentionally small and practical. It gives the repository a clean entry point without overengineering the documentation layout.
